## 🌟 Overview

**AURA AI** is a multi-purpose AI platform developed as a final project during the **Huawei ETA / HCIA AI Training Program**.

The platform integrates three independent AI models, each designed for a different real-world problem:

- 💳 **Credit Card Fraud Detection**
- 🏠 **House Price Prediction**
- 🍅 **Tomato Leaf Disease Detection**

AURA AI also integrates **Google Gemini** as an intelligent conversational and explanation layer.

The system is designed around a simple principle:

> **The Machine Learning models generate the predictions, while Gemini explains and communicates those predictions to the user.**

Gemini does **not** replace or override the predictions generated by the trained models.

# 🧠 AI Models

## 1. 💳 Credit Card Fraud Detection

A machine learning classification model designed to identify potentially fraudulent credit card transactions.

### Model

**XGBoost Classifier**

### Performance

**Accuracy: 99.98%**

### Input

The model accepts structured transaction features through the API.

The platform supports batch prediction through:

- CSV
- Excel
- API requests

### Output

The system returns:

- Fraud / Legitimate classification
- Prediction result
- Model response
- Batch prediction results
- Validation errors when required columns are missing or invalid

---

## 2. 🏠 House Price Prediction

A regression model designed to estimate house prices from structured property information.

### Model

**Stacking Regressor Pipeline**

The pipeline includes feature engineering and preprocessing before generating the final prediction.

### Performance

**R² Score: 94.5%**

### Feature Engineering

The backend performs additional feature engineering including:

- `TotalSF`
- `TotalPorchSF`
- `TotalBath`
- `HouseAge`
- `RemodAge`
- Quality ordinal encoding

The model output uses an inverse logarithmic transformation to return the estimated house price.

### Output

The API returns:

- Individual property predictions
- Predicted prices
- Minimum predicted price
- Maximum predicted price
- Mean predicted price
- Median predicted price
